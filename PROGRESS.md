## Сделано

- [x] **S0 — протокол v1.** Конверт (цель, задача, capability, бюджет токенов, мандат, цена, TTL, подпись), канонизация, Ed25519 с публичным ключом внутри, HMAC-запасной путь, JSON Schema (экспорт из кода), мандат (4 правила, отказ по умолчанию), роутер (capability ∩ мандат ∩ цена, отказ с причинами).
      Тесты: `test_protocol.py`, `test_conformance.py` (12 проверок соответствия), `test_hardening.py`, `test_regressions.py` — 73 зелёных.
- [x] **S0.1 — транспорт.** HTTP на стандартной библиотеке (`/v1/messages`, `/v1/inbox`, `/v1/claim`, `/v1/complete`, `/v1/route`, `/v1/envelopes/{id}`, `/healthz`) + MCP-адаптер (7 инструментов, stdio/HTTP).
      Критерий: живой смоук всех эндпоинтов + нагрузка 8×25 = 200 запросов, 0 обрывов, ~132 req/s.
- [x] **S0.2 — память и история.** Три яруса (очередь SQLite / факты FTS5 trigram с версиями и связями / артефакты по sha256 с проверкой содержимого); жёсткий бюджет токенов; деградация объявлена (`dropped`); история — хеш-цепочка с `verify_chain`.
- [x] **S0.3 — набор соответствия.** Любая реализация подключается через `MITRA_CONFORMANCE_IMPL` → `SOMA_CONFORMANCE_IMPL`; 12 свойств: подпись, подмена, бюджет, деградация, TTL, эксклюзивность claim, объяснённый отказ, закрытие конверта, передача бюджета и мандата, имя правила в отказе, непризнание повторного id, происхождение по реестру ключей.
- [x] **S0.4 — ревью пантеоном, два круга.** Первый: 6 critical + 10 high (мёртвый HTTP-транспорт, обходимый мандат, мандат не вызывался, подпись без авторства, тихая деградация). Второй: 8 регрессий от моих же правок (`route` ломал подпись, отказ сжигал конверт, sqlite ронял 14 из 200 запросов, рвалась цепочка истории). Закрыто, у каждого дефекта — регрессионный тест.
- [x] **S0.5 — переименование в Soma.** Репозиторий `mitra-hub` → `soma-protocol`, пакет `mitra` → `soma`, протокол `mitra/1` → `soma/1`, CLI `soma`, MCP-инструменты `soma_*`, переменные `SOMA_*`, каталоги `~/.soma/`.
      Решение владельца 21.10.2026; выполнено в день публикации — цена переименования близка к нулю, цена путаницы с «Mitra Core» — нет.

## Дальше (по порядку)

- [ ] **S1 — швы и плагины.** Пять интерфейсов в `soma/interfaces.py`: `Signer`, `MandateEvaluator`, `MemoryTier`, `Meter`, `Anchor`. В OSS — минимальные эталонные реализации с пометкой «reference»; движки Mitra Core (attest, drift, agentpay, indra-memory) подключаются плагинами.
      Критерий: `pip install "soma-protocol[engines]"` поднимает хаб на наших движках; движки не копируются в OSS-репозиторий.
- [ ] **S2 — карта разграничения.** Раздел в README: что открыто, что закрыто, почему так. Плюс `extras` в `pyproject` для движков.
      Критерий: новичок за 2 минуты понимает, что мы отдаём и что продаём.
- [ ] **S3 — протоколы рядом.** Адаптер A2A (конверт → задача, `agents.json`) + приём x402-квитанции (сумма сверяется, подпись и сеть — на транспорте).
      Критерий: конверт уходит в чужой агент по A2A и оплачивается по x402.
- [ ] **S4 — серверный профиль.** Аутентификация, квоты, лимиты, TLS-ready, метрики. Сегодня референсный транспорт без аутентификации — это осознанно и написано в README, но публиковать его наружу нельзя.
      Критерий: `SOMA_MANAGED=1` поднимает хаб, готовый к публикации.
- [ ] **S5 — реестр и доверие.** Внешние агенты, KYA, репутация по фактам (подписанные квитанции, не лайки).
      Критерий: первый внешний агент в реестре, его подпись проверяется по ключу.
- [ ] **S6 — федерация.** Два и более узлов, общая память с разграничением прав, внешние якоря (Arweave/IPFS) для истории.
      Критерий: узлы видят друг друга; история переживает смерть одного узла.

## Правила проекта

1. **Фикс без регрессионного теста — отложенный баг.** Каждый дефект получает тест.
2. **Публичный репозиторий — сначала ревью, потом публикация.** Транспорт проверяется живым смоуком, включая нагрузку.
3. **Протокол открыт всегда.** Движки — наша экономика и в OSS не попадают.
4. **Никаких новых продуктов без новой боли.** Soma — не продукт, а протокол; продукт — Mitra Core.
5. **Деплой против документации:** README/PROTOCOL/SECURITY обязаны совпадать с кодом; расхождение — дефект.
6. **Молчание не считается ответом:** отказ, деградация и потеря — объявляются явно.
