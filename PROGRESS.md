## Дальше (по порядку)

- [x] **S1 — швы и плагины.** Пять протоколов в `soma/interfaces.py`: `Signer`, `MandateEvaluator`, `MemoryTier`, `Meter`, `Anchor`. Сборка компонентов `soma/components.py`: эталоны (Ed25519Signer, RuleMandate, Memory, UsageMeter, LocalChain) + плагины из `SOMA_PLUGINS="модуль:фабрика"` и из точек входа группы `soma.plugins`. Хаб работает через швы, а не напрямую.
      Коммит `8322c2c`. Тесты: `tests/test_components.py` (9) — включая главное: **плагин реально меняет поведение** (движок отказал без явного мандата, конверт не сгорел) и битый плагин не ломает хаб.
      Побочный эффект, найденный тестом: оценщик мандата раньше звался только при наличии мандата в конверте — движок с собственными правилами не мог отказать. Теперь шов зовётся **всегда**.
      Критерий: `pip install "soma-protocol[engines]"` поднимает хаб на наших движках; движки не копируются в OSS-репозиторий.
- [x] **S2 — карта разграничения.** Раздел README «What is open and what is not»: протокол — MIT навсегда, движки — закрыты, сервис — закрыт; почему именно так и что это значит для того, кто строит на Soma. Плюс инструкция «Plugging your own engine» (два способа подключения, пример, что показывает `/healthz`) и группа точек входа `soma.plugins` в `pyproject.toml`.
      Коммит `8322c2c`.
      Критерий: новичок за 2 минуты понимает, что мы отдаём и что продаём.
- [x] **S3 — протоколы рядом.** Адаптер A2A (`soma/a2a.py`): конверт ↔ задача/сообщение, карточка агента по стандартным путям `/.well-known/agent-card.json`; чужая задача без `metadata.soma` отвергается, а не принимается за нашу. Платёжный контракт: `cost_usdc` (цена работы) против `price_usdc` (потолок отправителя); без квитанции работа не выдаётся (`code: payment_required`), конверт остаётся в очереди; квитанция проверяется на сумму, актив и получателя, подпись и сеть — на транспорте. Платёжный контракт включён в набор соответствия (**C13**).
      Коммит `797787c`, тесты `tests/test_s3.py` (10).
      Критерий: конверт уходит в чужой агент по A2A и оплачивается по x402.
- [x] **S4 — серверный профиль.** Управляемый режим `SOMA_MANAGED=1`: обязательный bearer-токен (`SOMA_TOKEN`; если токен не настроен — вход закрыт целиком), квота отправки на отправителя в час (`SOMA_QUOTA_PER_HOUR`, чужой не тратит чужую), настраиваемый лимит тела (`SOMA_MAX_BODY`). Локальный режим по умолчанию сохранён — для работы за своим шлюзом.
      Коммит `e9a5ce8`, тесты `tests/test_s4.py` (6); живой смоук: без токена 401, с токеном 200.
      Критерий: `SOMA_MANAGED=1` поднимает хаб, готовый к публикации.
- [x] **S5 — реестр и доверие.** Реестр как файл (name, capabilities, цена, публичный ключ). **KYA:** хаб выдаёт одноразовый нонс, агент подписывает его своим ключом — чужим ключом в реестр не попасть, нонс одноразовый. **Квитанции:** исполнитель подписывает результат (agent, envelope_id, result_hash, ts), хаб сверяет подпись по ключу реестра и засчитывает — непроверенная квитанция не считается. **Нарушения:** отказ по мандату фиксируется против агента, который его допустил. **Репутация** = `verified_receipts − 4 × breaches`, статус `unknown/observed/established/breached`; считается из фактов, пересчитывается любым.
      HTTP: `GET /v1/agents/nonce?agent=`, `POST /v1/agents` (регистрация с доказательством), `GET /v1/reputation?agent=`, квитанция в `POST /v1/complete`.
      Тесты `tests/test_s5.py` (13).
      Критерий: первый внешний агент в реестре, его подпись проверяется по ключу.
- [x] **S6 — федерация.** Видимость в конверте (`private` по умолчанию | `shared` | `public`): приватный конверт **не уходит** никуда — это правило, а не ошибка. Общий конверт подписывается узлом-отправителем; получатель сверяет подпись **по своему реестру**, чужой ключ — отказ. История переносима: узел отдаёт хеш-цепочку, другой принимает и проверяет непрерывность — «история переживает смерть узла» без блокчейна (внешний якорь — адаптер, а не требование).
      HTTP: `POST /v1/federate/push`, `POST /v1/federate/inbox`, `GET /v1/federate/outbox`, `GET /v1/federate/pull?peer=`, `GET/POST /v1/history`.
      Тесты `tests/test_s6.py` (8) + живой смоук двумя узлами: приватный не ушёл, общий принят, история A (3 записи) принята и проверена узлом B. Коммит `6f14917`.
      Критерий: узлы видят друг друга; история переживает смерть одного узла.

## Правила проекта

1. **Фикс без регрессионного теста — отложенный баг.** Каждый дефект получает тест.
2. **Публичный репозиторий — сначала ревью, потом публикация.** Транспорт проверяется живым смоуком, включая нагрузку.
3. **Протокол открыт всегда.** Движки — наша экономика и в OSS не попадают.
4. **Никаких новых продуктов без новой боли.** Soma — не продукт, а протокол; продукт — Mitra Core.
5. **Деплой против документации:** README/PROTOCOL/SECURITY обязаны совпадать с кодом; расхождение — дефект.
6. **Молчание не считается ответом:** отказ, деградация и потеря — объявляются явно.
